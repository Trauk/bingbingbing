# 需求对照

把考核任务逐条对到实现位置。凡是没做到的，第 4 节如实列出。

## 1. 基础任务

| 考核要求 | 实现方式 | 代码位置 |
|---|---|---|
| 检测指定颜色（红蓝色）的装甲板 | 灰度阈值 150 二值化 → 外轮廓 → `minAreaRect` 拟合灯条 → 长宽比/长度/倾角筛选 → 两两配对（长度差、y 差、中心距、垂直度、颜色一致）→ 共用灯条去重；颜色用 R−G / B−G 通道差判定 | `src/detector.cpp`：`detect()`、`checkLightbar()`、`checkArmor()`、`colorOf()` |
| **标出四个角点** | 四角取左右灯条的上/下短边中点，按 左上 → 右上 → 右下 → 左下 排列，画绿色四边形 + 四个彩色角点 | `src/detector.cpp` 组装 `Armor::corners`；`src/visualizer.cpp` `draw()` |
| **标出中心点** | 四角坐标的均值，画黄色实心圆 + 十字 | `src/detector.cpp` `armor.center`；`src/visualizer.cpp` |
| **估计中心在相机坐标系的三维位置** | `undistortPoints` 去畸变 → 3D 点取 135×56 mm → `solvePnPGeneric(SOLVEPNP_IPPE)` → 按 z>0、法向 n·t>0、重投影最小选解 → `solvePnPRefineLM` 精化；`tvec` 即板中心在相机系的位置（米） | `src/solver.cpp`：`solve()`、`objectPoints()`、`undistortCorners()` |
| 解的自检 | 重投影误差 ≤ 5 px；距离 1–2.2 m；耗时 2–3 ms | `src/solver.cpp` 的 `reproj_error`；`src/profiler.cpp` |

## 2. 画面显示与输出

| 考核要求 | 实现方式 | 代码位置 |
|---|---|---|
| 画面显示检测结果 | 四角、中心、颜色/大小/编号文字 | `src/visualizer.cpp` `draw()` |
| 画面显示三维位置 | 文字 `(x, y, z) mm` 与 `distance m` | `src/visualizer.cpp` |
| 画面显示处理耗时 | 左上角 HUD：帧号、时间、单帧 ms | `src/visualizer.cpp` |
| 结果视频 | 每 6 帧抽 1 帧写 30 fps MP4 | `src/main.cpp`（`stride`、`VideoWriter`） |
| 结果文件 | 逐帧/逐板 CSV：frame、timestamp、valid、color、x/y/z、distance、reproj、ms | `src/main.cpp`（CSV 写入） |

## 3. 附加项

| 项目 | 状态 | 说明 |
|---|---|---|
| 复杂背景/强光 | 部分 | 白/蓝白背景用通道差排掉；未做自适应阈值 |
| 数字识别 | 未做 | 已知限制 |
| 跟踪/预测 | 未接入 | `Tracker` 有匀速模型接口，未进主流程 |
| 处理速度 | 已统计 | 18-25：2.37 ms/帧；18-28：3.22 ms/帧 |
| YOLO | 未使用 | 纯传统视觉 |

## 4. 没做到 / 已知限制

- 目标转到侧面、正面装甲接近 90° 时，两根灯条几乎重合，18-25 段约 69 帧漏检；
- 蓝方没有样本，蓝色分支未实测；
- 大装甲板 230×56 未验证；
- 没有数字识别、没有跟踪补帧、没有用 IMU 做世界系转换。
